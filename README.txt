SAILA'S STUDY HUB

FILES
- index.html : struktur halaman login dan dashboard
- style.css  : desain responsif feminin pink-biru
- script.js  : interaksi dan penyimpanan data

CARA MENJALANKAN
1. Ekstrak folder/ZIP.
2. Buka index.html menggunakan browser (Chrome/Edge/Firefox).
3. Buat akun demo melalui Create an account, lalu login.
4. Isi fitur dashboard. Data disimpan otomatis di localStorage browser.

CATATAN PENYIMPANAN & AKUN
Versi ini adalah prototype front-end. Data tersimpan pada browser/perangkat yang digunakan dan tidak otomatis tersinkron ke perangkat lain. Menghapus data situs/browser dapat menghapus data tersebut. Login demo bukan sistem autentikasi aman untuk produksi; jangan gunakan password penting.

GOOGLE CALENDAR
Tombol Google Calendar saat ini menampilkan pemberitahuan konfigurasi. Integrasi sungguhan memerlukan Google Cloud project, OAuth 2.0 client ID, izin Google Calendar API, dan implementasi backend/konfigurasi domain yang sesuai. Jangan menaruh client secret di JavaScript publik.
